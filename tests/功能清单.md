# 欢洋生活 · 功能清单（全量扫描 v2.3.0）

> 扫描方式：app.json 页面注册 + 各页 WXML/JS 事件与数据 + 云函数 action。版本 2.3.0。

## 全局能力
- 隐私合规弹窗（privacy-popup）：登录/头像/剪贴板/相册前授权，getPrivacySetting + requirePrivacyAuthorize + openPrivacyContract
- 云开发：login / family / syncCheckin / syncHome / remind 五个云函数；家庭码双人同步
- 5 个 Tab：今日 / 菜单 / 健身 / 冰箱 / 我的（另有 引导、备菜、提交建议、查看建议 4 个二级页）

## 今日页 today
- T1 问候区：日期、问候语、目标、家庭状态；点击跳「我的」
- T2 今日习惯：逐项打卡/取消、🔥连续天数、云同步 habit-* 记录
- T3 临期食材提示：今天建议吃（剩余天数 ≤1）
- T4 今日三餐计划：模块开关控制显隐；冰箱空时提示采购
- T5 三餐打卡：早/午/晚，六选一（按菜单/在家做/外卖/聚餐/外食/没吃），云同步 meals
- T6 补剂打卡：开关、完成数、模块开关+补剂开关控制显隐
- T7 今日训练：模块开关控制显隐；打卡/取消+震动+云同步

## 菜单页 meals
- M1 7 天菜单自动生成（冰箱库存驱动、临期优先、口味/喜好加权）
- M2 缺料清单（冰箱自动比对、建议买）
- M3 采购清单：单项/一键全选，purchase-done 持久化，进度百分比
- M4 备菜步骤：单项/一键全选，prep-done 持久化
- M5 菜单拖拽排序 → menuOverride 云同步；恢复默认；重新生成（清除覆盖）
- M6 菜单/备菜双视图切换（seg）；下拉刷新

## 健身页 fitness
- F1 自定义运动打卡：篮球/羽毛球/其他（自定义名）+ 时长 30/45/60/90；今日已记/取消；云同步
- F2 今日训练打卡/取消：连续天数🔥、最近 7 天记录
- F3 周课表拖拽排序 → profile.trainOrder 云同步；恢复默认
- F4 动作库展示
- F5 运动模块关闭时整页空状态提示

## 冰箱页 fridge
- R1 库存列表：分类/位置/入库日/建议食用日/剩余天数/状态（新鲜/临期/过期）+ 统计（临期/过期数量）
- R2 食材入库：名称/分类/位置，库存驱动后续菜单
- R3 吃掉了：删除食材并云同步（含拉取竞态保护）
- R4 下拉刷新拉云端冰箱

## 我的页 profile
- P1 微信登录 / 退出登录（清空本机、云端保留、重登恢复）
- P2 头像（chooseAvatar 上传云存储、隐私授权）+ 昵称（云同步成员）
- P3 家庭：创建 / 加入（邀请码+关系）/ 成员列表 / 改名（创建者）/ 复制邀请码（剪贴板）/ 微信分享邀请 / 退出·解散
- P4 完善我的生活方式入口（引导页）
- P5 基础数据：性别/目标/身高/体重/蛋白·热量目标/BMI
- P6 补剂管理：今日页显示开关、自定义补剂增删
- P7 我的习惯：模板池添加、自定义添加（名称自动生成图标）、删除、按标签更新
- P8 功能模块开关：三餐/运动/补剂（今日页显隐，可全部关闭）
- P9 自动日志：近 7 天（三餐快照/补剂/运动），折叠展示
- P10 作息与喜好：上班/睡觉时间、口味、喜好食材 chips（添加/删除/清空/自定义输入）
- P11 每日提醒：订阅消息开启/重新授权
- P12 使用建议入口：提交建议 / 查看建议

## 生活方式引导页 onboarding
- O1 人格大方向选择（1~3 个）+ 细分兴趣多选
- O2 完成生成专属习惯：持久化 tags/subTags/habits/modules；再次进入回显已选

## 使用建议 suggest / suggestions
- S1 提交建议：文字（≤500）+ 最多 3 张图片（相册选图、预览、删除、压缩上传云存储）
- S2 查看建议：家庭模式看本家庭、单人模式看自己；昵称/时间/文字/图片

## 云函数
- login：获取 openid
- family：create / join / pull / push / info / setRelation / setNickname / setAvatar / setName / setGender / leave / suggestAdd / suggestList（集合 families、checkins、suggestions 自动创建）
- syncCheckin：打卡记录拉/推（补剂/训练/自定义运动/三餐/习惯）
- syncHome：历史遗留同步函数（客户端未直接调用）
- remind：每日订阅消息提醒（定时触发）
