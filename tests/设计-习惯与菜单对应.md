# 选择习惯 ↔ 菜单对应关系设计（v2.3.6）

## 目标
首次进入自动引导选择生活方式（人格+细分+习惯）；菜单引擎按人格标签加权，
让“选了什么习惯 → 看到对应风格的菜单”；我的习惯页支持一键“重新选择”，减少零散操作。

## 人格标签 → 菜单加权规则（负数=更优先，叠加计算）

| 人格 | 菜单规则 |
| --- | --- |
| 💪 运动型 | 高蛋白菜优先：proteinG≥30 得 -2，≥24 得 -1 |
| 🧘 养生型 | 带蔬菜（veg 非空）得 -1；元素≥3 得 -1；辣度≥2 扣 +2 |
| 🍜 吃货型 | 热量≥250kcal 得 -1；营养元素≥2 得 -1 |
| 🐶 懒狗型 | 快手菜优先：cookTime≤10 分钟得 -2，≤15 分钟得 -1 |
| 🌙 夜猫型 | 辣度≥2 的菜扣 +2（晚餐清淡助眠） |
| 📚 卷王型 / 💰 搞钱型 / 🎮 宅家型 / ☕ 社牛型 | 中性，不加权 |

口味（清淡/微辣/偏辣）与喜好食材沿用原有规则，与人格加权叠加。

## 用户流程（减少操作）
1. 首次进入小程序（未选过人格）→ 自动跳转「选择生活方式」
2. 选择人格大方向（1~3 个）+ 细分兴趣 → 完成
   - 生成：tags / subTags / 推荐习惯（替换旧推荐，保留自定义习惯）/ 功能模块默认
   - 保存并云同步 → 返回今日页，菜单按人格加权显示
3. 「我的习惯」页提供：
   - 🎯 重新选择生活方式（重新进入引导，回显当前选择，改完一次到位）
   - ➕ 添加习惯（模板池/自定义，自动图标）
   - 按标签更新习惯（保留标签，只重排推荐习惯）
4. 不想选也可点「暂时跳过」：本次不再自动弹，我的页保留入口。

## 数据字段
- person.tags：人格标签数组（如 ['💪 运动型','🌙 夜猫型']）
- person.subTags：细分兴趣
- person.habits：习惯（key/name/icon/freq）
- 菜单预读取 prefs.tags 参与 generateWeekMenu 排序
