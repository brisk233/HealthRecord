## 四点半、隐私合规配置（审核必做，一次性）
1. mp.weixin.qq.com → 设置 → 服务内容声明 → 用户隐私保护指引 → 新建/更新：
   - 收集信息勾选：**微信昵称、微信头像、相册（仅选择照片）**；处理的信息中写明**用户 openid**
   - 用途说明示例：「昵称/头像用于在家庭中展示成员身份；openid 用于识别账号并同步家庭数据（冰箱库存、菜单、打卡）；相册照片用于用户提交使用建议时上传，仅读取用户主动选择的图片」
   - 第三方共享：勾选「微信云开发（云函数/云存储/云数据库）」
   - **必须勾选「剪贴板」**：代码里「复制邀请码」调用 wx.setClipboardData，属隐私接口；不声明会被审核拦截（提示 Clipboard），发布后该权限也会被回收
   - **删除多余权限**：手机号、位置信息、照片/视频信息 我们未使用，必须从指引中删除
2. 保存后**发布指引**（发布成功后再去提交代码审核；不要在指引审核期间反复提交，容易看到「未采集用户隐私」的旧状态）。客户端已内置隐私弹窗与授权流程（getPrivacySetting / requirePrivacyAuthorize / openPrivacyContract），剪贴板写入与相册选择已纳入授权流程，无需再改代码。
3. （可选，v0.11.3 起不再必需）云存储权限：控制台 → 存储 → 权限 → 所有用户可读。头像现已由云函数管理员权限转临时链接，默认权限下双方也能互看。

> v2.3.0 新增「使用建议」：提交（文字+最多3张图片）与查看列表由 family 云函数 suggestAdd/suggestList 存取，集合 suggestions 自动创建；**需重新部署 family 云函数**，并在隐私指引勾选「相册」。

## 五、部署与更新速查（云开发版）

### 首次部署（做一次即可）
1. 云开发控制台 → 数据库 → 创建集合 `homes`、`checkins`（权限：所有用户不可读写）
2. 左侧 cloudfunctions 根目录右键 →「选择云环境」→ cloudbase-d1glhkgunaf107df5
3. 对 4 个云函数目录逐个右键 →「上传并部署：云端安装依赖」：login / syncHome / syncCheckin / remind
   - remind 部署时会弹「更新云调用权限」→ 勾选 subscribeMessage.send → 点「立即更新」
4. 工具点「上传」→ 填版本号（如 0.2.0）→ mp.weixin.qq.com 后台 → 版本管理 → 开发版本 →「选为体验版」→ 成员管理把另一半加为体验成员
5. 两台手机「我的」页填同一个家庭码 → 同步生效；「开启每日提醒」并勾选「总是保持以上选择」

### 以后每次代码更新
- 小程序端页面/逻辑改动：点「上传」新版本号 → 后台「选为体验版」→ 手机端自动更新
- 云函数改动：对应云函数目录右键 →「上传并部署：云端安装依赖」
