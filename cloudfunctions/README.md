# 云函数部署步骤（第 3 周）

## 一、数据库集合（✅ 无需手动创建，全自动）
family / syncCheckin / remind 云函数在**首次运行时会自动创建** `families` 与 `checkins` 集合。
数据只通过云函数（管理员权限）访问，小程序端无直接读写能力，安全上等同「所有用户不可读写」。
（可选）旧版 `homes` 集合可到控制台手动删除。

## 二、部署云函数（微信开发者工具）
在工具左侧文件树中，对 cloudfunctions 下的 5 个目录分别右键 →「上传并部署：云端安装依赖」：
- login（获取 openid）
- family（v0.4.0 家庭：创建/加入/拉取/推送/信息/关系备注）
- syncCheckin（打卡同步）
- remind（临期定时提醒，每天 8:00 触发）
- （可选）syncHome 为旧版兼容，可不再部署

## 三、存储权限（让对方看到你的头像）
云开发控制台 → 存储 → 权限设置 → 选择「所有用户可读，仅创建者可读写」。
否则家庭成员之间无法加载对方上传的头像（显示为默认 👤）。

## 四、订阅消息模板（提醒功能）
✅ 已完成：模板「日程提醒」已申请，模板 ID 已填入代码。字段映射：活动名称(thing1)=临期食材提醒 · 开始时间(date2)=北京时间 · 温馨提示(thing3)=建议今天吃掉或冷冻处理 · 详情(thing4)=临期食材清单。
如需更换模板：把新模板 ID 填到 cloudfunctions/remind/index.js 和 miniprogram/utils/cloudsync.js，并按新模板字段调整 data，然后重新部署 remind 云函数。

## 四、使用
1. 两台手机打开小程序 →「我的」→ 填写同一个家庭码 → 保存
2. 「我的」→ 开启每日提醒（订阅一次）
3. 之后档案、冰箱、打卡都会在两台手机间实时同步
