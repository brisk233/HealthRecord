## 1. 历史与定位

### 1.1 是什么

小六壬是中国古代的一种**掌诀类占卜法**，俗称**报时起课法**：

> "小六壬，古代中国占卜法之一，俗称报时起课法。以大安、留连、速喜、赤口、小吉、空亡六位分列食指、中指及无名指上；占时按月、日、时顺序求之；得大安、速喜、小吉者为吉，其余为凶。"
> —— 《道家秘术》第16章"小六壬"，QQ阅读 <https://book.qq.com/book-read/24108691/16>（等级 C，但内容与《玉匣记》原文一致）

它的三个本质特征：
1. **只有 6 个结果**（六宫/六神），没有卦象、没有爻、没有天盘地盘；
2. **靠"数"在手掌 6 个位置上循环点数**得出结果（掐指一算）；
3. **输入只有 3 个数**：月、日、时（或任意三个数）。

**《玉匣记》原文（转引自 sohu 简史，等级 A 转引）**：

> **李淳风六壬时课**
> 其法每从大安上起正月，月上起日，日上起时。假如三月初五日辰时，三月在速喜上，就速喜上起初一，初五在大安，大安上起子时，数至辰时即是小吉，以类推占，余皆仿此。

这段是**目前可考的最早、最"正统"的算法定义**，本报告第 3 章的算法即以此为准。

### 1.4 与 大六壬 / 六爻 / 梅花易数 的区别

| 维度 | 小六壬 | 大六壬 | 六爻（纳甲筮法） | 梅花易数 |
|---|---|---|---|---|
| 体系类型 | 掌诀/循环点数 | 式法（天地盘+四课三传） | 纳甲装卦 | 象数+体用 |
| 起课输入 | 月/日/时 或任意三个数 | 月将加占时（太阳过宫定月将） | 摇钱六次成卦 | 时间/数字/外应起卦 |
| 结构 | 6 宫 | 12 天地盘、四课、三传、十二天将、神煞 | 六爻+六亲+六神+世应 | 本卦/互卦/变卦 + 体用生克 |
| 结果粒度 | 单一结果（吉凶/方向/成败） | 极细，可看多方关系与细节 | 信息量中等，"万金油" | 重趋势与过程 |
| 学习成本 | 极低（2 小时可上手） | 极高（需大量记忆） | 中等 | 低，但"提高难" |
| 常见定位 | "专攻近期具体事情结果" | "最全能的术数工具" | "什么都能做，样样七八十分" | "擅长判断过程趋势" |

来源：
- 易德轩《面对不同的术数预测，给大家科普一下各个术哪方面比较强》<https://m.yi958.com/tiebi/posts/58696>（等级 C）
- 易半仙《相对比较好学的是梅花易数和小六壬…》<https://www.yibanxian.com/article-790-1.html>（等级 C）
- 大六壬的权威描述见《御定六壬直指·起例》（识典古籍）<https://www.shidianguji.com/zh/book/SDZJ0728/chapter/1kg328b67xgcr>（等级 A）："以太阳为主……入亥宫，即用亥为月将""以月将加之，顺布十二宫""取四课法""取三传法（贼克、比用、涉害、遥克、昴星、伏吟、返吟、别责、八专）"

**划重点（写文案时不能说错的地方）**：
> "真正研究过大六壬或天罡掌诀或走马六壬的人都知道，小六壬实质上和作为式法类的六壬完全没有关系。" —— sohu 简史
> 大六壬的"六壬"来自"六十甲子中以壬为首的六个干支（壬子、壬戌、壬申、壬午、壬辰、壬寅）"；小六壬只是借了"六壬"这个名头。

### 1.5 日本六曜（文化输出的活化石）

- **六曜**=先胜·友引·先负·佛灭·大安·赤口，是日本日历上最常见的历注。
- 辞书明确其来源："中国の六壬時課や小六壬と呼ばれる時刻・日の吉凶占いが**室町時代**に日本に伝わって変化したもの"（中国的六壬时课/小六壬于室町时代传入日本演变而成）。
- 俗说"孔明六輝"（诸葛亮发明）**不可信**："三国時代から六曜があったかは疑わしい"。
- 江户时期起初名为"即吉、共引、周吉、虛亡、泰安、赤口"，19 世纪初才变为今天的名称（此细节来自 sohu 简史；辞书只给出"江户后期流行"）。
- 明治 6 年（1873）改太阳历后，六曜被改造成"日的吉凶"占法，沿用至今。

来源：weblio 辞书 <https://www.weblio.jp/content/六曜>（含デジタル大辞泉 / 世界宗教用語大事典 / Wikipedia 三个词条，等级 A/B）

**产品启示**：小六壬在日本的"落地形态"是**日历+宜忌**，而不是占卜 App。小程序如果想降低"迷信感"，可以走"今日六曜/今日宜忌+传统文化科普"的轻量路线。

## 2. 六个宫位（六神）

### 2.1 掌诀定位与循环顺序（工程常量）

~~~
左手：食指根部 = 大安      食指指尖 = 留连      中指指尖 = 速喜
     无名指指尖 = 赤口    无名指根部 = 小吉    中指根部 = 空亡
~~~

顺时针（掌诀）循环顺序**永远固定**：

~~~
大安 → 留连 → 速喜 → 赤口 → 小吉 → 空亡 → （回到大安）
  0      1      2      3      4      5
~~~

> 来源：《道家秘术》第16章 <https://book.qq.com/book-read/24108691/16>；邵一尘《道家小六壬》"六种掌诀定位" <https://889sw.com/detail?id=1097>；江氏教程8 <http://jiangyangjun.com/post/88.html>（三处完全一致）

**注意**：顺序 ≠ 吉凶顺序，也 ≠ 五行相生顺序，更 ≠ 十二地支顺序。

### 2.3 吉凶等级（可直接做排序/UI 配色）

> "六神共有三吉三凶，分别以大安、速喜、小吉为吉，以留连、赤口、空亡为凶。三吉神里以**大安为大吉、速喜为中吉、小吉为小吉**，三凶里以**留连为小凶、赤口为中凶、空亡为大凶**。"
> —— 邵一尘《道家小六壬》<https://889sw.com/detail?id=1097>（等级 B）

| 等级序（好→坏） | 宫位 | 建议 UI |
|---|---|---|
| 5 | 大安 | 绿／大吉 |
| 4 | 速喜 | 暖绿／吉 |
| 3 | 小吉 | 浅绿／小吉 |
| 2 | 留连 | 灰黄／小凶（且有"变数"） |
| 1 | 赤口 | 橙红／中凶 |
| 0 | 空亡 | 深灰／大凶 |

注：也有人认为赤口某些事项比空亡更凶（邵一尘："断出行，空亡也有未出行之意，而赤口多为车祸等意外事故"）。**建议产品上不做绝对排序展示，用文字强弱描述代替。**

### 2.4 传统断辞原文（玉匣记"李淳风六壬时课"）

> 转引自 sohu《正经严肃的小六壬简史》<https://m.sohu.com/a/145558810_723725/>（等级 A 转引，未直接核对原书）

~~~
大安：身未动时，属木青龙，谋事一五七。
断曰：大安事事昌，求财在坤方，失物去不远，宅舍保安康，
      行人身未动，病者主无妨，将军回田野，仔细更推详。

留连：卒未归时，属水元武，谋事二八十。
断曰：留连事难成，求谋日未明，官事凡宜缓，去者未回程，
      失物南方见，急讨方心称，更须防口舌，人口且平平。

速喜：人便至时，属火朱雀，凡谋事主三六九。
断曰：速喜喜来临，求财向南行，失物申未午，逢人路上寻，
      官事有福德，病者无祸侵，田宅六畜吉，行人有信音。

赤口：官事凶时，属金白虎，凡谋事主四七十。
断曰：赤口主口舌，官非切宜防，失物速速讨，行人有惊慌，
      六畜多作怪，病者出西方，更须防诅咒，诚恐染瘟疫。

小吉：人来喜时，属水六合，凡谋事主一五七。
断曰：小吉最吉昌，路上好商量，阴人来报喜，失物在坤方，
      行人即便至，交关甚是强，凡事皆和合，病者祷上苍。

空亡：音信稀时，属土勾陈，凡谋事主三六九。
解曰：空亡事不长，阴人小乖张，求财无利益，行人有灾殃，
      失物寻不见，官事有刑伤，病人逢暗鬼，禳解保安康。
~~~

### 2.7 逐宫速查卡（产品卡片文案，可直接落库）

> 综合 sohu 掌诀断辞 + 邵一尘《道家小六壬》 + 江氏教程16–21 + 易德轩《华山派小六壬》

#### 大安（大吉 · 静 · 东方木）
- **一句话**：不动、安稳、有成——事情会成，但多半靠"等"和"被动"，不宜强求、不宜远行。
- **象意**：家宅、房屋、树木、四肢、肝、胆；天气雷、云；人物为长者、贵人、官印；味道酸；房为楼房。
- **数字**：口诀 1、5、7；宫位/排序数 1、4、5；隐藏数 7。
- **关键字**：静止、心安、吉祥、被动求谋、休养生息。
- **邵一尘**：大安是"睡龙"，虽吉但"因安生逸"，缺少主动性；断人行动则"身未动"。
- **江氏**：宜静之事占大安吉；求财开店（坐商）吉、行商不利；对方主动找我合作吉、我主动找对方差；属"被动求谋"。
- **贵人方向**：西南、东北吉；忌西、西北；南方多破耗。
- **贵人属相**：贵人属牛、鼠、羊、马；小人属龙、鸡。
- **应期数**：1、5、7（"寻人一五七日见"）。

#### 留连（小凶 · 拖延 · 北方水／四方土）
- **一句话**：拖、缠、反复、暗昧不明——事难成，宜缓不宜急；**留连是六宫中唯一"有变数"的宫**，晚上占得尤为不定。
- **象意**：坑洼、有水之地、长形房；胃、肾、血液；天气雨；味道咸；田宅、奴仆、阴私、桃花。
- **数字**：口诀 2、8、10；宫位/排序数 2、7、8；隐藏数 8。
- **江氏**：短期求财占留连不吉；长期求谋（开店）"前期一般、后面能赚"；主背后有隐情、猫腻；占外出人归期"一时半会回不来"。

- **象意**：角落、山地、坎坷不平处；肺、气管、呼吸系统；天气寒冷、霜；味道辣；房为平房。
- **数字**：口诀 4、7、10；宫位/排序数 1、2、4；隐藏数 10。
- **江氏**：不宜投资，适合外出打工；合作谨慎防纠纷；出行不急则缓；占生产多剖腹产；求医宜西医；学业主理科；性格主人仗义讲义气、好交友，但易言过其实。
- **贵人方向**：东方、东南吉。
- **应期数**：4、7、10。

## 3. 起课算法（核心，可直接编程）

### 3.1 数据模型

~~~ts
// 六宫（固定顺序，索引即"掌诀位置"）
export const PALACES = ["大安", "留连", "速喜", "赤口", "小吉", "空亡"] as const;
export type Palace = typeof PALACES[number];

// 十二时辰（索引 1..12，子=1）
export const HOURS = ["子","丑","寅","卯","辰","巳","午","未","申","酉","戌","亥"] as const;

export interface QikeInput {
  month: number;   // 农历月 1..12
  day: number;     // 农历日 1..30
  hour: number;    // 时辰序号 1..12（子=1）
}

export interface QikeResult {
  monthPalace: Palace;  // 月宫（也叫"前宫"）
  dayPalace: Palace;    // 日宫（"中宫"）
  hourPalace: Palace;   // 时宫（"末宫"/落宫，断事主看此宫）
  monthIndex: number;   // 0..5
  dayIndex: number;
  hourIndex: number;

~~~

### 3.2 传统算法（玉匣记原文规则，**唯一权威版本**）

原文："其法每从大安上起正月，**月上起日，日上起时**。"

**三条规则（必须一字不差地实现）**：

1. **月上起月**：不论问哪个月，**都从"大安"当作正月开始数**，顺时针数到所求月份 → 得**月宫**。
2. **月上起日**：**从月宫的位置当作"初一"**，顺时针数到所求日 → 得**日宫**。
3. **日上起时**：**从日宫的位置当作"子时"**，顺时针数到所求时辰 → 得**时宫**（结果宫）。

**数学形式（关键，工程必须按这个写）**：

~~~text
设 M = 农历月(1..12)，D = 农历日(1..30)，H = 时辰序号(1..12，子=1)
宫序（0-based）：0=大安 1=留连 2=速喜 3=赤口 4=小吉 5=空亡

月宫 index = (M - 1) mod 6
日宫 index = (M - 1 + D - 1) mod 6 = (M + D - 2) mod 6
时宫 index = (M - 1 + D - 1 + H - 1) mod 6 = (M + D + H - 3) mod 6
~~~

**等价的和数取余写法（很多在线资料用，但极易写错，见 3.5）**：

~~~text
r = (M + D + H - 2) mod 6      // r ∈ {0,1,2,3,4,5}
若 r = 0 → 第 6 宫 = 空亡
否则 r = 1..5 → 大安(1) 留连(2) 速喜(3) 赤口(4) 小吉(5)
~~~

### 3.3 参考实现（TypeScript，可直接粘贴）

~~~ts
const PALACES = ["大安", "留连", "速喜", "赤口", "小吉", "空亡"] as const;
const mod = (n: number, m: number) => ((n % m) + m) % m;

/** 传统"寅上起月、月上起日、日上起时" */
export function qikeTraditional(month: number, day: number, hour: number) {
  if (month < 1 || month > 12) throw new Error("month 必须为农历 1..12");
  if (day < 1 || day > 30)   throw new Error("day 必须为农历 1..30");
  if (hour < 1 || hour > 12) throw new Error("hour 必须为时辰序号 1..12（子=1）");

  const monthIndex = mod(month - 1, 6);
  const dayIndex   = mod(month + day - 2, 6);
  const hourIndex  = mod(month + day + hour - 3, 6);
  return {
    monthIndex, dayIndex, hourIndex,
    monthPalace: PALACES[monthIndex],
    dayPalace:   PALACES[dayIndex],
    hourPalace:  PALACES[hourIndex],
  };
}

/** 等价的"和数取余"写法（返回 1..6 的宫序号） */
export function qikeBySum(month: number, day: number, hour: number) {
  const r = mod(month + day + hour - 2, 6);
  return r === 0 ? 6 : r;  // 6 = 空亡
}

/** 报一个数（数字起课）：余数决定起点宫，再在该宫起时辰 */
export function qikeByOneNumber(n: number, hour: number) {
  const startIndex = mod(n - 1, 6);                       // n ÷ 6 的余数（余 0 → 空亡）
  const hourIndex  = mod(startIndex + hour - 1, 6);       // 在该宫起子时，数到所求时辰
  return {
    numberPalace: PALACES[startIndex],
    hourIndex,
    hourPalace: PALACES[hourIndex],
  };
}

/** 报三个数（前/中/末三宫派）：三数各自从大安起数 */
export function qikeByThreeNumbers(a: number, b: number, c: number) {
  return {
    frontIndex: mod(a - 1, 6),   // 前宫（远端/对方/将来）
    middleIndex: mod(b - 1, 6),  // 中宫（中间人/过程）
    lastIndex: mod(c - 1, 6),    // 末宫（我自己/现在，断事主看此）
    frontPalace: PALACES[mod(a - 1, 6)],
    middlePalace: PALACES[mod(b - 1, 6)],
    lastPalace: PALACES[mod(c - 1, 6)],
  };
}
~~~

### 3.4 为什么"大安起正月、日上起时"？（传统解释，写文案可用）

1. **大安 = 寅位 = 正月**：农历（夏历）**正月建寅**，而掌诀上"大安"就落在食指根部对应的**寅位**。华山派口诀说得很直白："此十二节飞至最后到中指根（就是丑位），**为什么从寅上起呢，是因为寅上是正月**，十二指飞穴，是从月上起的六壬术，所以从寅上起，**寅上正月也**！"（易德轩《华山派小六壬 2》<https://qimen.yi958.com/lrrk/11852>）
2. **三层递推 = 天地人**：道传体系把月宫/日宫/时宫合称"**天地人三盘**"，分别代表**起因、经过、结果**（邵一尘《道家小六壬》<https://889sw.com/detail?id=1097>）。月→日→时是"由大到小、由远及近"的时间收敛过程。
3. **子时为一日之始**：日宫起子时，与"日从子时换"的时辰制度一致。
4. **历史真相（重要，别在文案里乱认祖）**：这套"年上起月、月上起日、日上起时"的轮掌取数法，少微垣考证认为**不会早于宋朝**，实际定型于**明代**（《事林广记》已见今名），**不可能是李淳风或诸葛亮所创**（李淳风卒于 670 年）。

### 3.5 ⚠️ 和数取余法的经典陷阱（工程必须知道）

网上流传最广的错误写法是：**"月+日+时 除以 6 取余，0 当 6"**。它**与玉匣记原文结果不一致**。

> 例：农历三月初五辰时
> - 传统掌诀：三月 → 速喜；速喜起初一 → 初五大安；大安起子 → 辰时**小吉**
> - 和数法（错误版）：3+5+5 = 13，13÷6 余 1 → **大安** ❌（错）
> - 和数法（正确版）：(13-2) mod 6 = 5 → 第 5 宫 = **小吉** ✅

"错误版"确实有来源——《java之小六壬算命代码实现》<https://cloud.tencent.cn/developer/article/2530605> 就写着"总和除以 6 取余，余数 1 大安、…、0（整除时视为 6）空亡"。**该文与《玉匣记》原文例子自相矛盾，不要照抄。**
（同一篇里"0 视为 6 = 空亡"的边界处理本身是对的，错的只是漏掉了 -2 修正。）

### 3.7 变通起课法（民间与各流派的"输入层"，**必须做成可插拔**）

| 方法 | 规则 | 流派/来源 | 备注 |
|---|---|---|---|
| **① 月日时起课（正统）** | 大安起月 → 月上起日 → 日上起时 | 玉匣记、QQ书、邵一尘、绝大多数教程 | 同一时辰内所有人同卦，这是它最大的产品缺陷 |
| **② 日时起课（江氏）** | **只用日+时**：大安起初一 → 日上起子时数到时辰；结果以时宫为"自身/太极点" | 江氏教程9 <http://jiangyangjun.com/post/89.html> | 省掉"月"，适配"任何一天来问事"的场景 |
| **③ 时刻起课（江氏）** | 大安起时辰 → 时辰落宫起"刻"（每 10 分钟一刻，一个时辰 12 刻，按子丑寅…排），再数到当前刻 | 江氏教程9 | 解决"同一时辰内多人同卦" |
| **④ 报一个数（江氏数字起课）** | 求测人随口报一个数（几位不限）→ **除以 6 取余数** → 余数从大安起数 → 在该宫起时辰 → 落宫为结果 | 江氏教程9 | 江阳君自称最常用；"每个人自己报的数最能代表当时状态" |
| **⑤ 报三个数** | 三个数**依次**当"月/日/时"用（如 7、1、8 → 从大安起 7 落大安 → 大安起 1 落大安 → 大安起 8 落留连 = 留连） | 易德轩《小六壬起课和常见断法》<https://qimen.yi958.com/lrrk/13420> | 也可一人报一个电话号码，从中取 3 个数 |
| **⑥ 三数定三宫（前/中/末）** | 三个数**各自**从大安起数，得**前宫/中宫/末宫**三神，再按"前=对方/将来、中=中间人/过程、末=我/现在"断 | 《小六壬之法1》<https://qimen.yi958.com/lrrk/196> | 与 ⑤ 完全不同！同一组数结果不同 |

### 3.8 数字取余的边界处理（**必须写进代码注释**）

| 情形 | 处理 | 依据 |
|---|---|---|
| 余数为 0（整除 6） | **视为第 6 宫 = 空亡** | 腾讯云《java 小六壬》明确："0（整除时视为 6）对应空亡"；易德轩《小六壬预测法》："除尽了就是第六爻空亡" |
| 报数 > 6 | 一律先 mod 6（江氏："不论求测人报多大的数，用这个数除以 6，用所得的余数从大安开始起课"） | 江氏教程9 |

| 报数 = 0 | 未见于资料。工程上建议按 mod 6 = 0 处理为空亡，并在 UI 提示"请报 1 以上的数" | **不确定项** |
| 月 > 12 / 日 > 30 | 输入校验直接拦截 | — |
| 时辰跨日（23:00–24:00 子时） | 资料只给"子时 23–1 点"，**未说明算今日还是次日** | **不确定项**，见 3.10 |

### 3.9 江氏"装卦"完整流程（进阶版，一课多断用；**这是目前最工程化的一套**）

江氏小六壬 = 传统六宫 + **地支 + 六亲 + 六神 + 五星**，共 5 层。流程（依据江氏教程 9/10/11/14/15 与官方案例教程46 <http://jiangyangjun.com/post/126.html>）：

**第 0 步 起课**：得到 **日宫** 与 **时宫**（时宫也叫"自身宫/太极点"）。
**第 1 步 装地支**：时宫所对应的地支为该宫的"自身"地支，然后**顺时针隔位排**（每次 +2）：
~~~text
地支[i+1] = 地支[i] + 2 (mod 12)
例：时宫=赤口(戌) → 小吉(子) 空亡(寅) 大安(辰) 留连(午) 速喜(申)
~~~
**第 2 步 装六亲**（以"自身"地支五行为我）：
~~~text
生我者 = 父母    我生者 = 子孙    克我者 = 官鬼
我克者 = 妻财    同我者 = 兄弟
~~~
**第 3 步 装六神**（按自身地支起青龙，顺时针 青龙→朱雀→勾陈→白虎→玄武→腾蛇）：
~~~text
子午 → 大安起青龙      丑未 → 留连起青龙
寅申 → 速喜起青龙      卯酉 → 赤口起青龙
辰戌 → 小吉起青龙      巳亥 → 空亡起青龙
~~~
**第 4 步 装五星**（从"日落宫"起木星；时刻/日时起课取时宫，数字起课取数字落宫；顺时针 木→火→土→金→水→空）：
~~~text
木星(起) → 火星 → 土星 → 金星 → 水星 → 天空
~~~
**第 5 步 取用神断事**：考试以**官鬼**为用神、寻物以**父母**为用神、求财以**妻财**为用神、婚姻以**妻财/官鬼**为用神……

**官方案例全文（教程46，报数 9 + 未时，可直接做回归测试）**：
~~~
第一步 起课：报数 9 → 大安=1…9 落"速喜"；从速喜起时辰，子丑寅…未 → 落"赤口"（未为自身）
第二步 装地支：赤口未 → 小吉酉 → 空亡亥 → 大安丑 → 留连卯 → 速喜巳
第三步 装六亲：自身未土；酉金=我生→子孙；亥水=我克→妻财；丑土=同→兄弟；
                卯木=克我→官鬼；巳火=生我→父母
第四步 装六神：丑未留连起青龙 → 留连青龙、速喜朱雀、赤口勾陈、小吉白虎、空亡玄武、大安腾蛇
第五步 装五星：以数字落宫起木 → （原文作"小吉木、空亡火、大安土、留连金、速喜水、赤口天空"）
第六步 取用神：问高考 → 以官鬼为用神 → 官鬼临留连，留连主反复 → 断考不上（卦主反馈：确实没考上）
~~~
> ⚠️ **原文自相矛盾点**：该文第一步说"数字 9 落在速喜"，第五步却以"小吉"起木星。按教程15的规则（以数字落宫起木星），应为 **速喜木、赤口火、小吉土、空亡金、大安水、留连空**。**工程实现请以教程15的规则为准**，此案例的五星以笔误论。

## 4. 断课维度（拿到宫位之后怎么解读）

### 4.1 通用断课流程（可直接做成产品引导步骤）

各家说法基本一致，综合成 6 步：

1. **明确所问之事**（问什么就按什么断，不能一卦乱断）；
2. **静心起课**（"闭目静思问题，心中默念几遍后起课"——QQ书《道家秘术》"难点释疑"）；
3. **定三宫**：月宫/日宫/时宫（或前/中/末宫），**以时宫（末宫/落宫）为主**；
4. **先断吉凶，再断细节**（邵一尘："就算别人问的是数字性问题，你也要先以卦的吉凶论事，然后才看数字"）；
5. **结合所问之事与五行生克**（江氏："以时宫为太极点，综合六宫、六神、六亲、五星、地支的生克冲合"）；
6. **取数定应期 + 定方位/人事**。

### 4.2 分类速断歌诀（**这是最现成的文案库**）

> 来源：易德轩《小六壬起课和常见断法》<https://qimen.yi958.com/lrrk/13420>（等级 C，但结构清晰、可直接落库）

~~~
【寻人法断】
大安人回来，留连在家中，速喜须相见，白虎在它乡，
小吉在路中，空亡出外方。

【失物法断】
大安去远东方，留连眼前北方，速喜见现南方，白虎人收西方，
小吉山林东方，空亡路旁中央。

【病人法断】
大安不久病离床，留连不久病难当，小吉时中为吉利，
白虎知时是重衰，速喜男轻女便重，空亡到底是空亡。

【行人法断】
大安身未动，留连人未见，速喜立时见，白虎在它乡，
小吉终须到，空亡即世亡。

【官非法断】
大安事不成，留连实是忧，速喜人和散，白虎见官方，
小吉须消散，空亡即不妨。

【赌博法断（可用于抽奖/博彩类问题）】
大安来不得，留连本无收，速喜加倍利，白虎支财多，
小吉本有利，空亡本无收。
~~~

### 4.5 应期（什么时候应验）——四套可并行的方法

**方法一：宫位应期数（最常用，直接取数）**
> 来源：《小六壬之法1》<https://qimen.yi958.com/lrrk/196>、口诀"谋事主…"

| 宫位 | 应期数（=口诀"谋事数"） | 宫位数/排位数（第二套） | 隐藏数 |
|---|---|---|---|
| 大安 | 1、5、7 | 1、4、5 | 7 |
| 留连 | 2、8、10 | 2、7、8 | 8 |
| 速喜 | 3、6、9 | 3、6、9 | 9 |
| 赤口 | 4、7、10 | 1、2、4 | 10 |
| 小吉 | 1、5、7 | 5、3、8 | 11 |
| 空亡 | 3、6、9（原文作 1、5、7，疑误） | 6、5、10 | 12 |

用法：**先看吉凶，再取数**。单位按事情性质选：日内事取"日"，月内事取"月"，年事取"年"；配合"日/时"换算（如"速喜 3 日到账""留连四五月之后"）。邵一尘的例子："问货款几天到？落速喜 → 火克金为收入 → 断 3 天"。

**方法二：地支取应期（邵一尘："应期本是地支转"）**
- 六宫各有"寄宫地支"（大安寅卯、留连丑辰、速喜巳午、赤口申酉、小吉未戌/亥子、空亡亥子/戊己——两套详见 2.2）。
- 应期即该地支所主的月/日/时（如落大安取寅月/寅日）。

## 10. 一页速查（给产品/文案同事）

- **本质**：6 个宫、3 个数、绕手掌顺时针数一圈 = 结果。
- **算法一行版**：`时宫 index = (农历月 + 农历日 + 时辰序号 - 3) mod 6`，0=大安…5=空亡。
- **报数一行版**：`(报数 - 1) mod 6` 得起点宫，再在该宫起子时数到当前时辰。
- **三吉**：大安（不动之吉）、速喜（快速之吉）、小吉（和合之吉）。
- **三凶**：留连（拖延，唯一有变数）、赤口（口舌血光）、空亡（落空，**凶事占之反吉**）。
- **最常用的 4 个输出**：落宫 + 一句话吉凶 + 应期区间（快/中/慢）+ 方位。
- **最大的产品缺陷**：同一时辰内所有人同卦 → 必须提供"报数起课"作为默认入口。
- **最大的合规风险**：把娱乐内容包装成"能决定人生决策的预测"。
